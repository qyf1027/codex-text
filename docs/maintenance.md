# 维护

上游快照由 `skills-lock.json` 固定；上游完整仓库只应临时下载到仓库外。

升级步骤：

1. 读取锁文件，用 Git 检出所记录的官方仓库，选择并审查目标提交。
2. 比较对应 Skill 目录的全部变化，检查脚本、外链、依赖与许可变更。
3. 仅替换目标 Skill 目录，完整保留其相关文件；不要拷入上游 `.git`。
4. 更新锁文件中的提交和所有文件 SHA-256，不要仅修改校验值来掩盖差异。
5. 若升级 Playwright CLI，固定明确 npm 版本，更新并提交 package-lock.json。
6. 运行 `npm run check`、必要的浏览器功能检查，提交说明中记录升级原因。

`npm run check` 检查已安装快照完整性、文件增删和 Skill 基础元数据，
不是行为遵循测试。新 Skill 或本地内容改写需要额外场景验证。
新任务的自动发现也必须在新任务实际验证，不能从校验结果推断。
