# IPD Smart Tracker Web App

这是独立运行的 React + TypeScript + Vite 应用。项目会自动保存在当前浏览器的 IndexedDB；导出 JSON 可备份或转移到另一浏览器。核心排期、风险识别和本地保存不需要 Gemini 密钥或网络服务。

## 本地运行

需要 Node.js 18+：

```sh
npm ci
npm run dev
```

按 Vite 输出的本地地址在浏览器打开。生产构建与测试：

```sh
npm test
npm run lint
npm run build
```

## 已可操作的功能

- 多项目切换、新建与归档；保留原 ZIP 的 55 项 IPD 任务作为初始项目。
- 阶段、任务、成果与 GA 管理；成果可作为跨项目任务的前置条件。
- 周一至周五工作日排期、实际日期优先、循环依赖校验、失效或缺失前置成果风险。
- 独占资源预约和重叠风险提示。
- 标准预测、未采纳的启发式压缩候选与用户确认的计划版本，原始基准和实际数据分别保存。
- 完整工作区备份与恢复、单项目导出和导入；导入前进行校验并要求确认。

## 计算口径与限制

计划开始日算第 1 个工作日，成果交付后的下一工作日才可计划启动后续任务。日期以 `YYYY-MM-DD` 保存；法定节假日未纳入。候选方案是启发式建议，不保证数学最优；系统不得把候选当作实际完成。风险历史保留首次发现信息。
