# IPD Smart Tracker

主要 Web App 位于 [web/](web/)。这是基于 React、TypeScript 和 Vite 的本地优先项目管理应用；安装、启动与测试命令见 [Web App 使用说明](web/README.md)。

`preview.html` 是此前交付的单文件 HTML 预览，保留供快速查看原版界面。它的数据与 `web/` 应用互不同步。后续开发以 `web/` 为准。

完整需求基线见 [PRD](docs/requirements/IPD_Smart_Tracker_PRD_v1.0.md)，当前覆盖范围见 [实现状态](IMPLEMENTATION_STATUS.md)。
